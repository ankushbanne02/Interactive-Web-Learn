Create a **high-quality interactive educational website for a Science Park Exhibit** titled:

**“Electricity Generation – The Science Behind Power.”**

The website should be designed **especially for children visiting a science park**, so the interface must be:

• Colourful
• Interactive
• Large readable text
• Friendly icons
• Touch-screen friendly (for kiosks)

Use a **modern tech stack**:

React
React Three Fiber (Three.js)
TailwindCSS
Framer Motion for animations

The background theme should be **dark space-style like a science simulation**, but UI cards and buttons should be **bright, colorful, and playful**.

---

# LANGUAGE SYSTEM (IMPORTANT)

The first page must ask the user to **select a language**.

Supported languages:

• English
• Marathi

When the user selects a language:

• Store it in **global state / context / localStorage**
• All pages after that must automatically appear in the **selected language**

Examples:

If English selected → entire site English
If Marathi selected → entire site Marathi

Translate all:

• Titles
• Buttons
• Instructions
• Quiz questions
• Quiz explanations
